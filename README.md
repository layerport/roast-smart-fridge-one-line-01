## The entry

`main.py` writes a single original roast line about the entrant's own smart fridge to `/output/entry.txt` — it texts that we're out of eggs while I'm standing right in front of it holding the eggs. Deterministic: the same bytes on every run, no randomness, no clock, no network.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
